## Core Requirements

### 1. Layout Component

- Header, Sidebar, Main, Footer structure
- Responsive support (mobile, tablet, desktop)
- Dark mode support

### 2. Navigation

- Router integration
- Active state display
- Mobile hamburger menu

### 3. Common UI Components

- Button (primary, secondary, danger)
- Input (text, password, email)
- Card
- Modal
- Toast/Alert

### 4. API Client

- Base URL configuration
- Interceptors (auth token, error handling)
- Type safety
