# Scope: 2026-S1 (Basic Todo)

> L2: Scope Definition

## Direction

Build minimal full-stack Todo app:
- Backend: REST API with SQLModel
- Frontend: React UI connecting to API

Focus on simplicity - demonstrate the workflow, not complex features.

## Target

### Backend (services/example-service/)
- Health endpoint
- Todo CRUD endpoints
- SQLite database

### Frontend (apps/example-app/)
- Todo list display
- Add/toggle/delete todo
- API integration

## Priority

1. Backend API setup
2. Frontend UI setup
3. Integration

## Success Criteria

- [ ] `pnpm dev` runs both services
- [ ] CRUD operations work end-to-end
- [ ] Clean, minimal code
